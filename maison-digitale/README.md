# Maison Digitale — WordPress theme (Elementor)

The approved Maison Digitale design, built as a WordPress theme where **every section is an Elementor widget**. All text, images, videos, links and lists are editable in Elementor.

## Install

1. WordPress 6.2+ and PHP 7.4+.
2. Plugins → Add New → install and activate **Elementor** (the free version is enough).
3. Appearance → Themes → Add New → Upload Theme → choose `maison-digitale.zip` → Activate.
4. You land on **Appearance → Maison Digitale**. Click **Import demo pages**.
   This creates every page of the design, the header and footer templates, sample blog notes, and sets the homepage.

## Editing

- Open any page → **Edit with Elementor**. Click a section to edit it. In the panel, all widgets are under **Maison Digitale**: drag them in, reorder, duplicate or delete.
- **Gold words in a headline:** wrap them in `*asterisks*`, e.g. `Let’s work *together.*`
- **Homepage scrolling:** each "Home —" widget is one full-screen panel. The side dots, the light/dark navigation switch and the one-scroll-one-panel behaviour are automatic. Add, remove or reorder panels freely; set each service panel's tone (light/dark) so they alternate.
- **Page look** (navigation colour, homepage snapping, footer, Arabic direction): Elementor's page settings (cog, bottom left) → **Maison Digitale page**.
- **Header and footer:** Templates → Saved Templates → "Site Header" / "Site Footer" (and Arabic versions). Edit once; they appear everywhere.
- **Blog:** write notes in Posts → Add New (normal WordPress editor). The theme sets them in the article design; a Quote block becomes the gold pull quote. Make a post sticky to feature it.
- **Forms** (contact, newsletter, brand audit, enquiry) email the address set in Appearance → Maison Digitale and are saved under **Form entries** in the dashboard. Make sure your host can send email (an SMTP plugin is recommended).
- Text in `[square brackets]` is placeholder content from the design, still to be supplied.

## Notes

- Flyhead is bundled from the brand files. Confirm the Headfonts licence covers web embedding before going live.
- Reduced-motion visitors get no snapping, no loader and no typed animation, as specified.
- On screens under 820px the homepage scrolls normally, one idea per screen, and the hero video becomes the poster image.
